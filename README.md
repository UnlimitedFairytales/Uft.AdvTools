# Getting started

## Install via git URL

https://github.com/UnlimitedFairytales/Uft.AdvTools.git?path=Assets/Uft.AdvTools

## Setup dependencies

- com.unity.ugui 2.0.0
    - Import TMP Essentials
- com.unity.2d.sprite 1.0.0
- com.unity.cinemachine 3.1.5
- https://github.com/Cysharp/UniTask.git?path=src/UniTask/Assets/Plugins/UniTask
- https://assetstore.unity.com/packages/tools/animation/dotween-hotween-v2-27676
    - Setup DOTween
    - Create ASMDEF
    - Project Settings > Player > Scripting Define Symbols > UNITASK_DOTWEEN_SUPPORT
- https://github.com/GlitchEnzo/NuGetForUnity.git?path=/src/NuGetForUnity
    - CsvHelper 33.1.0
- https://github.com/UnlimitedFairytales/Uft.UnityUtils.git?path=Assets/Uft.UnityUtils
    - Project Settings > Player > Scripting Define Symbols > UNITYUTILS_CSVHELPER_SUPPORT
- https://github.com/UnlimitedFairytales/Uft.FadeEffects.git?path=Assets/Uft.FadeEffects
- https://github.com/UnlimitedFairytales/Uft.VirtualizedList.git?path=Assets/Uft.VirtualizedList
