# 2. 素材について

以下の素材は、いらすとや の利用規約(2025/11/21時点)に基づき使用しています。
利用規約では個人・商用利用、改変が許可されています。
再配布（素材そのものをダウンロード可能な状態で提供など）を目的とした利用は許可されていません。
1つの制作物に対して21点以上利用する場合は、有償になります。
著作権はいらすとや側にあります。
本プロジェクトへの同梱は規約に基づく適法な利用です。
